A-steroids

A small solo project by me, inspired by the classic Asteroids game.

About

A simple clone of Asteroids with an added local 2-player mode. This was a fully solo project, where I created all the art, sound, and programming.

Process

Art/Visuals: I created all the art assets in Procreate on an iPad. While I don’t consider myself an artist, I’m proud of the results I achieved with this project.

Sound/Music: For this game, I sourced all the sound assets online and used Audacity to edit and customize them to fit my needs.

Code: I initially followed a tutorial to recreate the basic mechanics of the original Asteroids game. From there, I replaced all the assets and added a local 2-player mode allowing players to share the same keyboard.
